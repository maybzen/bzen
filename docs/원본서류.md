# 원본서류 보관 (Google Drive)

- 폴더: https://drive.google.com/drive/folders/1iJK4DeFh9bty8SHIXv8qv4JiYp6LnoC-
- 구성: 급여대장 / 카드명세서 / 세금납부서 / 원천징수영수증
- 용도: 급여대장·명세서·납부서 PDF 원본 보관 (장부 입력 근거)
- 주의: 주민번호·급여 포함 — 리포지토리(공개)에 절대 커밋 금지

## 작업 방식

1. 새 자료는 위 Drive 폴더에 업로드 (보관용)
2. 장부 입력이 필요하면 채팅에 파일 첨부 (Drive 목록은 직접 조회 불가)
3. 입력 완료 후 입력 내역은 홈페이지 장부에서 확인
