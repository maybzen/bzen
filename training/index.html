비젠 인트라넷 연습용 홈페이지

실제 사이트와 똑같은 메뉴·똑같은 순서의 빈 껍데기입니다. 숫자는 0건, 저장은 안 됩니다.
위 관리자 보기 / 직원 보기를 누르면 메뉴가 바뀌는 것도 실사이트와 동일합니다.

메뉴 18개 전체 수록실화면 이미지는 변형 없이 그대로인쇄 → PDF 교육자료로 사용 가능

0. 먼저 보기 — 역할별 메뉴 지도

버튼을 누르면 해당 메뉴 설명으로 이동합니다. ★ = 관리자 전용

관리자: 18개 전부 보임. 직원: 설정 + 공통권한(기본: 지출결의·운영비·프로젝트·거래처·휴무대장)에 허용된 메뉴만 보임. 대시보드·구성원·급여관리·계정관리·자금관리·휴지통은 직원에게 안 보임.

연습 방법 (3분)

  1. 위에서 관리자 보기 → 왼쪽 메뉴 18개가 다 보이는지 확인.
  2. 직원 보기로 전환 → 메뉴가 5~6개로 줄어드는지 확인 (실사이트와 동일).
  3. 왼쪽 메뉴를 순서대로 클릭 → 각 화면의 따라하기대로 빈 표에 가상으로 입력해 보기.
  4. 실화면(회색 박스 사진)은 원본 그대로 — 숫자·이름만 마스킹됨. 변형·합성 없음.
회계 규칙 요약: 금액은 공급가액+부가세 분리 입력 → 합계 자동. 손익 = 순매출액(공급가액) − 매입 = 매출총이익 − 운영비 = 영업이익. 부가세는 손익 제외. 프로젝트 손익은 직접 입력 금지, 장부 지정 시 자동 집계. 급여는 귀속월(일한 달) 기준. 지출결의는 승인절차 없는 기록 전용.
