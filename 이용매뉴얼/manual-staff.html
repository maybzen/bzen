1. 로그인

  1. 배포 주소 접속 → 전달받은 아이디·초기 비밀번호로 로그인.
  2. 오른쪽 위 이름 → 설정에서 비밀번호를 본인 것으로 변경.
  3. 비번을 잊으면 본인이 찾을 수 없습니다. 관리자에게 재설정 요청.

4. 운영비·장부 보기

운영비도 생길 때 바로 입력합니다 (허용된 메뉴가 보일 때).
  • 대시보드: 기간 고르기 → 숫자·추이 확인.
  • 장부: 기간·검색·프로젝트 필터 → 조회. 남의 글은 보기만, CSV 내보내기 가능.
  • 보고서(허용 시): 기간 → 인쇄/PDF 저장.

5. 프로젝트·거래처·휴무·내 정보

  • 프로젝트: 카드 클릭 → 내역 확인 (비용만 보일 수 있음, 정상). [프로젝트 등록]·카드 연필(수정)로 등록·수정은 직접 가능. 삭제는 관리자에게 요청.
  • 거래처: 검색 → 등록·수정 가능. 삭제는 관리자에게 요청.
  • 휴무(허용 시): [휴무 등록] → 종류·날짜·사유 → 저장 → 승인/반려 확인.
  • 설정: 이름·부서·전화 수정, 비밀번호 변경·로그아웃.
