1. 로그인

관리자 아이디는 이미 전달된 상태입니다. 회원가입이 필요 없습니다.

  1. 배포 주소 접속 → 전달받은 이메일·비밀번호로 로그인.
  2. 오른쪽 위 이름 → 설정에서 비밀번호를 본인 것으로 변경.
  3. 직원 가입은 로그인 화면 직원 가입하기 → 사용 승인 대기 중 → 관리자가 계정관리에서 승인.
마지막 관리자 1명은 권한을 내리거나 삭제할 수 없습니다.

5. 프로젝트·수금·거래처

  1. 프로젝트 등록을 먼저 → 장부에서 지정하면 손익 자동 집계. 손익 직접 입력 없음. 등록·수정은 직원도 가능, 삭제는 관리자만.
  2. 수금관리: [입금 등록] → 수금률·미수금 확인.
  3. 거래처: 등록·서류첨부·중복은 합치기. 서류삭제는 관리자만.

6. 자금관리·급여·구성원 (관리자 전용 ★)

  1. 자금관리: 자금현황 [잔고 기록] / 법인카드 파일업로드 → 분류 → [일괄등록].
  2. 급여관리: 급여대장 CSV 올리기 → 귀속월(근무한 달) 집계. 인별 명세서 저장 시 장부금액 자동 보정.
  3. 구성원: 인라인 편집 → 일괄저장.

7. 세금·보고서

  1. 세금관리: 연도 → 유형탭 → 체크·토글. 4대보험 고지서 업로드·CSV 지원.
  2. 보고서: 기간 → [요약CSV/상세CSV]·[인쇄/PDF] — 임원 보고용.
